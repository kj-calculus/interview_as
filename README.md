# 면접온 — 면접 방과후 관리

Node.js 24 이상에서 `npm install` 후 `npm start`로 실행합니다. 접속: http://127.0.0.1:4173

관리자·교사·학생 로그인, 반별 달력, 학생별 대학 일정 흐름, 대학 일정 및 방과후 수업·과제 등록/수정/삭제, ExcelJS 기반 XLSX 양식 다운로드와 계정 일괄 등록을 제공합니다. 실제 운영 데이터를 입력하도록 예시 계정과 일정은 제거했습니다.

최초 실행 시 관리자 `admin` / `admin123`을 생성합니다. 서버는 비밀번호를 salt가 포함된 scrypt 해시로 저장합니다. 최초 비밀번호는 `ADMIN_INITIAL_PASSWORD`로 지정할 수도 있으며, 기존 데이터베이스의 관리자 비밀번호를 재시작으로 덮어쓰지 않습니다. 로그인 후 상단에서 비밀번호를 변경할 수 있습니다.

교사·학생 계정 등록 시 초기 비밀번호 777777이 발급됩니다. 비밀번호 초기화 시에도 777777로 설정됩니다. 발급 완료 창에서 계정 발급 내역 엑셀을 저장하고 사용자에게 전달합니다. 첫 로그인 시 비밀번호 변경이 필수입니다. 관리자 또는 해당 반 교사가 계정 관리에서 학생 임시 비밀번호를 재발급할 수 있습니다. 교사 계정 재발급은 관리자만 가능합니다. 재발급하면 기존 로그인 세션이 만료됩니다.

엑셀 열은 학번 / 이름 / 권한 / 배정반 / 아이디 순서입니다. 관리자 양식 권한은 교사·학생 드롭다운, 교사 양식은 학생 및 본인 배정반으로 제한됩니다. 업로드 시 권한·반·아이디·학번 중복을 재검사하고 오류가 하나라도 있으면 전체 등록을 막습니다.

계정·일정·세션은 `data/interview.sqlite`에 저장합니다. 세션 쿠키는 HttpOnly/SameSite=Strict이며 유효 시간은 8시간입니다. 서버는 모든 API에 인증과 역할·반 권한을 적용합니다. 교사에게 다른 반의 학생·일정을 전송하지 않으며 학생은 본인 일정과 본인 반 방과후 수업만 조회합니다. 학생의 등록·수정 요청은 서버에서 차단합니다.

교사 또는 관리자가 대학 발표·면접 일정을 각각 등록합니다. 1차 발표가 없는 전형은 생략할 수 있습니다. 학생별 대학 일정표는 시간순으로 일정을 연결합니다.

로컬 실행은 `npm start`를 사용합니다. 온라인 버전은 Sites의 Cloudflare Worker와 D1 저장소를 사용하며 `npm run build`로 생성합니다. 온라인과 로컬 저장소는 독립적입니다. `cloud/worker.mjs`가 온라인 API이며 `db/schema.ts`와 `drizzle`에 데이터베이스 변경 이력을 관리합니다. 온라인 초기 관리자 비밀번호 해시는 Sites의 `ADMIN_INITIAL_HASH` 비밀 값으로만 설정합니다. 온라인 비밀번호는 Web Crypto PBKDF2-SHA256으로 저장하며 쿠키에 Secure 속성을 적용합니다. 서버 로그인 시도 횟수는 D1에서 제한합니다.

로컬 데이터 백업은 서버를 종료한 상태에서 `data` 폴더 전체를 복사합니다. SQLite 데이터와 발급 비밀번호 파일을 소스 저장소에 포함하지 마세요.

`npm test`로 실제 HTTP 로그인·권한·등록·수정·삭제·비밀번호 재발급·서버 재시작 후 보존과 XLSX 양식/화면 생성 로직을 검증합니다. 테스트는 임시 데이터베이스를 사용하며 실제 데이터는 수정하지 않습니다. 브라우저 시각 검증 및 지원 브라우저에서의 WebMCP 검증은 수행하지 않았습니다.
